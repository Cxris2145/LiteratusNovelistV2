menu_book Cómo se juega
  • Descifra el título, personaje o autor oculto seleccionando una letra a la vez.
  • Comienzas con 5 gotas de tinta en tu pluma. Cada letra incorrecta descuenta 1 gota.
  • Lee la pista literaria en pantalla para deducir de qué obra o personaje se trata.
  • Los acentos se descubren automáticamente al pulsar la vocal base (por ejemplo, pulsar A revela tanto A como Á).
stars Premios de Tinta
  • Cada victoria te otorga +15 Gotas de Tinta añadidas directamente a tu saldo.
  • Puedes obtener hasta 3 recompensas con premio al día para cuidar la economía del juego.
  • Al alcanzar el límite diario, puedes seguir jugando todas las partidas que desees para aprender y practicar.
  • Inicia sesión con tu cuenta para que la Tinta ganada se guarde en tu perfil.
